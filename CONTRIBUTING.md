# Contributing

Thanks for your interest in contributing! This is a GitHub profile repository,
so most of the content here is meant to showcase projects and ways to connect.

## Ways to contribute

- **Open issues** — found a bug in one of my projects? Open an issue on the relevant repository.
- **Submit pull requests** — improvements to any of the featured projects are always welcome.
- **Start a discussion** — questions, ideas, or collaboration ideas are all appreciated.

## Before you start

1. Check for an existing issue or discussion covering your topic.
2. Follow the existing code style and conventions of the project.
3. Keep changes focused — one logical change per PR.
